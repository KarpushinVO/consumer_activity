Проект поиска покупателей со снижающейся активностью покупок.

Используется пайплайн с несколькими моделями:

* Дерево решений;
* К-ближайших соседей;
* Логистическая регрессия;
* SVC;

В исходных данных был явный дисбаланс классов поэтому для оптимальной оценки использовалась метрика ROC-AUC.
Также для поиска гипер-параметров использовался RandomizedSearchCV из-за ограниченных вычислительных ресурсов.
