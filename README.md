Проект поиска покупателей со снижающейся активностью покупок.

Используется пайплайн со следующими моделями:

* Дерево решений;
* К ближайших соседей;
* Лог рег;
* SVC;



В исходных данных был явный дисбаланс классов поэтому использовался и для оптимальной оценки использовалась метрика ROC-AUC.
Также для поиска гипер-параметров использовался RandomizedSearchCV из-за ограниченных вычислительных ресурсов.
